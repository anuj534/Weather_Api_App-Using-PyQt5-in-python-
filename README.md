# 🌦️ Python Weather App (PyQt5)

A modern, lightweight desktop weather application built using **Python** and **PyQt5**. Designed as a cleaner, faster alternative to traditional weather tools, this app integrates a live weather API to deliver instant meteorological updates for cities around the world.

---

## ✨ Features

* **🌍 Global City Search:** Look up real-time weather data for any city worldwide.
* **🌡️ Live Temperature Tracking:** Displays accurate, up-to-date temperatures in **Celsius (°C)**.
* **😊 Dynamic Weather Emojis:** Automatically matches current weather conditions with intuitive emojis for at-a-glance readability.
* **📝 Clear Condition Summaries:** Provides straightforward descriptions of the current forecast (e.g., *clear sky*, *light rain*, *scattered clouds*).
* **🖥️ Modern GUI:** Built from scratch with **PyQt5** for a clean, responsive desktop experience.

---

## 🛠️ Tech Stack

* **Language:** Python 3
* **UI Framework:** PyQt5
* **Data Source:** Weather API (JSON / REST)
